# Security Policy

## Reporting a vulnerability

If you believe you've found a security issue in Corpus Stack, please do
not open a public issue. Instead, report it privately.

Use GitHub's [private vulnerability reporting](https://github.com/heuristicslab/corpus-stack/security/advisories/new)
to submit a report.

## Scope

Corpus Stack is a public directory site. It does not collect user data,
does not use authentication, and does not process payments. The attack
surface is limited.

Please report:

- Cross-site scripting (XSS) vulnerabilities
- SQL injection in any public query
- Exposure of environment variables or secrets
- Improper access controls on any endpoint

## Response

Reports will be acknowledged within 72 hours. Fixes will be deployed as
soon as is practical.
